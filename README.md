# KostManage

KostManage adalah aplikasi berbasis Flutter
yang dirancang untuk membantu pengelolaan
rumah kost secara digital.

## Tujuan Aplikasi

Mempermudah pemilik kost dalam mengelola
kamar, penghuni, tagihan, pembayaran,
dan pengaduan fasilitas.

## Pengguna Aplikasi

1. Admin / Pemilik Kost
2. Penghuni Kost

## Fitur Utama

- Login pengguna
- Dashboard admin
- Dashboard penghuni
- Manajemen kamar
- Manajemen penghuni
- Pengelolaan tagihan
- Pembayaran dan bukti transfer
- Pengaduan fasilitas

## Teknologi

- Flutter
- Dart

## Status Pengembangan

Project sedang dalam tahap inisialisasi.
